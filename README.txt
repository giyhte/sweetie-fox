SWEETIE FOX — лаунчер Minecraft 1.21.11 (Fabric)

КАК ПОЛУЧИТЬ .EXE (один раз, бесплатно)
1. Создай репозиторий на github.com и загрузи в него ВСЁ содержимое этой папки
   (вместе с папкой .github).
2. Вкладка Actions -> build-exe -> Run workflow. Через ~3 минуты в Artifacts появится DCODE-exe -> DCODE.exe.
3. Запусти DCODE.exe откуда угодно: он сам покажет установщик, поставится в AppData и
   создаст ярлык «DCODE» на рабочем столе. (Хочешь без установки — положи рядом файл portable.txt.)

БЕЗ GITHUB (нужен Python 3.10+): двойной клик по DCODE.pyw.

ЧТО ДЕЛАЕТ
- Игра/моды не установлены -> кнопка «УСТАНОВИТЬ» скачает всё. Уже есть -> просто «ИГРАТЬ».
- Меню в игре (Right Shift) собирается автоматически (кнопка «УСТАНОВИТЬ МЕНЮ»), лог: tools\build.log
- Все данные лежат рядом с exe (папки game, tools, bundle).

- Игра уже стоит и цела → повторно не качается (проверка файлов); принудительно — кнопка «Переустановить / обновить».

=== DCODE клиент + автосборка ===
1. Загрузи ВСЮ эту папку в GitHub-репозиторий (push).
2. Вкладка Actions -> build-exe соберёт: jar клиента (client-src) -> положит в лаунчер -> DCODE.exe.
3. Скачай DCODE.exe из Artifacts (или из Release, если создашь релиз).
4. Запусти DCODE.exe: он сам поставит Minecraft 1.21.4 + Fabric + моды + клиент DCODE.
Меню клиента в игре: правый Shift.
