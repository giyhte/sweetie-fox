СИСТЕМА ЛИЦЕНЗИЙ SWEETIE FOX — НАСТРОЙКА
=========================================

Из чего состоит
  server/license_server.py  — сервер (хранит ключи и аккаунты). Запускаешь ты, на своём сервере.
  admin/SweetieFoxAdmin.pyw — твоя программа: создаёшь ключи, видишь пользователей, баню, продлеваешь.
  pl/license.py, license_ui.py — часть лаунчера: приветствие, вход, регистрация, таймер.

1. Запусти сервер
   Нужен Python 3.8+ (больше ничего ставить не надо):
       python server/license_server.py
   Порт 8787 (поменять: переменная SF_PORT). База — server/licenses.db.
   При первом запуске создаётся server/admin_token.txt — это твой секретный токен админа. Никому не показывай.

   Где хостить:
     • дешёвый VPS (от ~3$/мес) — лучший вариант; поставь Caddy/nginx с HTTPS перед сервером;
     • PythonAnywhere / Render — подойдут, там используй объект `application` из license_server.py (WSGI).
   Без HTTPS пароли идут открытым текстом — для публичного использования HTTPS обязателен.
   Свою базу licenses.db бэкать!

2. Укажи адрес сервера в лаунчере
   Либо впиши в pl/license.py строку  SERVER = "https://твой-домен"  до сборки exe,
   либо положи рядом с SweetieFox.exe файл license_server.txt с адресом одной строкой.

3. Создавай ключи
   Запусти  admin/SweetieFoxAdmin.pyw  → адрес сервера + токен из admin_token.txt → «Подключиться».
   Вкладка «Ключи»: срок в днях (или «Навсегда»), число активаций, сколько ключей, заметка → «Создать».
   Ключ вида SFOX-XXXX-XXXX-XXXX отдаёшь пользователю. Срок начинает идти с момента регистрации.
   «Активаций» = сколько раз ключ можно использовать (1 = один человек). 0 = без лимита.
   Ключ можно отозвать/вернуть/удалить. Вкладка «Пользователи»: бан, +дни, «навсегда»,
   сброс привязки к ПК, удаление.

Как работает у пользователя
  Первый запуск: анимация «Добро пожаловать» → вкладки «Вход / Регистрация / Продлить».
  Регистрация требует ключ. В лаунчере сверху справа — логин и таймер «Лицензия: 29д 04:12:33»
  (жёлтый < 3 дней, красный < 1 дня). По окончании срока лаунчер возвращает на «Продлить» — вводится новый ключ.
  Аккаунт привязывается к одному ПК (HWID); пустить на другой ПК можно сбросом в админке.
  Время считается по часам сервера, подкрутка даты на ПК не помогает. Без интернета можно играть до 3 суток
  после последней успешной проверки.

ЧЕСТНО О ЗАЩИТЕ
  Лаунчер — это Python-программа в exe, её можно распаковать и вырезать проверку, а Minecraft можно
  запустить и мимо лаунчера. Система защищает от обычных пользователей (ключи, сроки, лимит активаций,
  бан, привязка к ПК), но не от человека с навыками реверса. Если нужно жёстче — следующий шаг:
  отдавать сборку мода/сборки только с сервера по токену сессии.
